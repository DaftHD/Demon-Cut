# Demon Cut name and logo

The Demon Cut **source code** is free software under AGPL-3.0-or-later. Like every GNU licence, the
AGPL grants no trademark rights (section 7(e)), so the **Demon Cut name and logo** are not part of
that grant.

The name and the logo in [`assets/`](assets/) belong to DaftHD
([@DaftHD](https://github.com/DaftHD)).

- **Fork it, change it, ship it.** Everything the AGPL allows is yours to do.
- **Give a modified build its own name and icon** if you distribute it, so nobody mistakes it for
  an official Demon Cut build.
- **Describing the relationship is always fine:** "a fork of Demon Cut", "compatible with
  Demon Cut", reviews, tutorials and screenshots need no permission.
